# Тест нескольких путей и стрелок

Это отдельный прототип. Основная игра и ветка `main` не изменяются.

## Запуск

```bash
pip install -r requirements.txt
python test_multitrack.py
```

## Управление

- **A** — выбрать верхнюю ветку.
- **D** — выбрать нижнюю ветку.
- **Space** — пауза.
- **R** — вернуть поезд в начало.
- **Esc** — выход.

В сцене показаны три параллельных пути, стрелочный перевод с двумя направлениями и небольшое депо с тремя отдельными составами. Вагоны игрока размещаются вдоль кривой маршрута, поэтому состав визуально проходит стрелку, а не телепортируется на соседний путь.

Это именно визуально-управляемый эксперимент: полноценной блокировки стрелок, сигнализации и диспетчеризации пока нет.
